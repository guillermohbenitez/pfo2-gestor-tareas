Sistema de Gestión de Tareas

PFO 2 · Programación sobre Redes · TSDS — Guillermo Benítez

Descripción

API REST en Flask con registro e inicio de sesión de usuarios, persistencia en SQLite y contraseñas hasheadas con werkzeug.security (scrypt + salt). Incluye un cliente de consola que consume la API.

Cómo ejecutarlo

pip install -r requirements.txt
python servidor.py      # inicia la API en http://127.0.0.1:5000
python cliente.py       # en otra terminal

GitHub Pages solo sirve contenido estático, por eso la API se ejecuta de forma local.

¿Por qué hashear contraseñas?

Para que, ante una filtración de la base de datos, nadie pueda conocer las contraseñas reales. El hash es de un solo sentido; la sal aleatoria evita las rainbow tables y un algoritmo lento como scrypt encarece los ataques de fuerza bruta.

Ventajas de SQLite

No necesita servidor ni instalación (viene con Python), toda la base es un único archivo, ofrece persistencia real con SQL estándar y restricciones como UNIQUE, y es liviano para un proyecto de este tamaño.
